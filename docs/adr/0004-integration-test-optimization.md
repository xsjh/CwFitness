# 集成测试优化 ADR

集成验证将区分为快速验证与完整回归：`npm test` 以 `core` 健康检查加按变更路径选择的测试组为日常门槛，冷启动目标不超过十分钟；`npm run test:full` 执行全部 HTTP 集成测试与 Chromium、Firefox、WebKit 浏览器回归，目标不超过二十五分钟。无法可靠归类的改动、依赖或测试基础设施变更一律升级为完整回归；这以偶尔较慢换取不因选择器遗漏而降低质量保证。

## Consequences

路径到测试组的关系由一份可审查的声明式清单集中维护，新增功能须同时更新该清单和测试。运行器输出数据库启动、迁移、HTTP、各浏览器项目及清理阶段的耗时；先以可见信号跟踪超标，连续两周稳定后再将时限设为 CI 硬门禁。完整回归先可在本地重复执行，随后成为合并 `main` 前与夜间监控的检查；只有在选择性执行和单次复用服务、数据库仍未满足预算时，才考虑严格隔离后的 Chromium 并行化。
